# モンスター作戦指示システム (Monster Tactical Directives System)

## 1. 概要
本ドキュメントは、プレイヤーが連れているアクティブパーティ（手持ち）の仲間モンスターに対して、ターンごとの行動方針（作戦）をリアルタイムに指示・切替を行う「モンスター作戦指示システム」の仕様を定義します。

本システムにより、戦闘時におけるモンスターの行動AIをプレイヤーが戦略的に制御できるようになり、リソース消費の抑制や回復優先行動、集団行動の維持などの柔軟な戦術が可能となります。

## 2. 作戦指示 (Tactical Directives) 一覧

作戦指示は `MonsterInstanceDomain` の `currentTactic` 属性で管理され、プレイヤーはダンジョン探索中いつでもコストなしで個体別またはパーティ一括で作戦を変更できます。

| 作戦コード | 作戦名称 | 概要 | 優先思考アルゴリズム |
| :--- | :--- | :--- | :--- |
| `FULL_POWER` | ガンガンいこうぜ | 威力の高い攻撃スキルや属性攻撃を最優先で使用し、最短で敵を撃破する。 | 威力最高スキル > 属性特効スキル > 通常攻撃 |
| `SAVE_RESOURCES` | 温存行動 | MPや専用リソースの消費を抑制し、通常攻撃メインで戦う。 | 通常攻撃 > 低コストスキル（MP70%以上時のみ） |
| `SAFETY_FIRST` | いのちだいじに | 自身およびプレイヤー・味方のHP回復・バフ・異常解除を最優先し、危機時は離脱する。 | 回復・解毒スキル > 防御バフ > 距離確保 > 通常攻撃 |
| `FOLLOW_ME` | ついでのサポート | プレイヤーの後方に密着追従し、プレイヤーが攻撃したターゲットを追撃する。 | プレイヤー追従 > プレイヤーと同ターゲット攻撃 |
| `FREE_ACTION` | 自由行動 | 種族固有の基本 AI（`NORMAL`, `COWARDLY`, `AGGRESSIVE` 等）に従って独立して行動する。 | 種族デフォルト AI に準拠 |
| `STAY_WAIT` | 待機命令 | 現在の座標から移動せず、隣接する敵のみを攻撃または防衛する。 | 隣接攻撃 > その場待機 |

## 3. 作戦別の詳細行動思考アルゴリズム

各ターンにおける仲間モンスターの行動決定時、指定された作戦指示に基づいて以下の思考ロジックが実行されます。

### 3.1 `FULL_POWER` (ガンガンいこうぜ)
1. **索敵**: 視界内（標準7マス）の敵エンティティを検索します。
2. **スキル選定**: 使用可能なスキル（MP充足かつ封印状態でない）の中から、**ダメージ倍率が最大**の攻撃スキルを選択します。
3. **攻撃実行**: ターゲットが射程内にいる場合、選定したスキルを発動します。
4. **追跡**: 射程外にいる場合、敵へ最短距離で接近します。

### 3.2 `SAVE_RESOURCES` (温存行動)
1. **索敵**: 視界内の敵エンティティを検索します。
2. **スキル制限**: 残り MP が最大 MP の 70% 未満の場合、すべてのスキル使用を禁止します。70% 以上の場合でも消費 MP 5 以下の低コストスキルのみ許可します。
3. **通常攻撃**: 隣接する敵へ通常攻撃を行います。
4. **追跡**: 隣接していない敵へ向かって1歩接近します。

### 3.3 `SAFETY_FIRST` (いのちだいじに)
1. **緊急判定**: プレイヤー、自身、またはパーティメンバーの HP が 40% 以下の場合、最優先で各種回復スキル・アイテム（特質所持時）を使用します。
2. **状態異常解除**: 状態異常にかかっている味方がいる場合、状態解除スキルを使用します。
3. **距離確保**: 自身の HP が 30% 未満かつ回復スキルがない場合、敵から遠ざかる方向へ退避（1歩移動）します。
4. **防衛攻撃**: 味方に危険がない場合のみ、通常攻撃を行います。

### 3.4 `FOLLOW_ME` (ついでのサポート)
1. **プレイヤー距離判定**: プレイヤーとの距離（マンハッタン距離）が 2 マス以上離れている場合、攻撃を行わずプレイヤーの隣接マスへ移動します。
2. **アシスト攻撃**: プレイヤーが前ターンに攻撃した敵ターゲットが存在する場合、そのターゲットを優先攻撃します。
3. **並行移動**: 敵がいない場合、プレイヤーの移動軌跡を追従します。

### 3.5 `STAY_WAIT` (待機命令)
1. **位置固定**: 移動コマンドを完全に拒否し、現在座標を維持します。
2. **迎撃**: 隣接マス（8方向）に敵が進入してきた場合のみ、通常攻撃または防御スキルを使用します。
3. **待機**: 隣接する敵がない場合、ターンをスキップ（足踏み待機）します。

## 4. 忠誠度 (Loyalty) と指示遵守判定ロジック

仲間モンスターが指示された作戦通りに行動するかどうかは、[モンスター忠誠度システム](./Monster-Loyalty-System.md) で管理される忠誠度値（`loyalty`: 0〜255）によって左右されます。

### 4.1 指示遵守確率 (Obedience Rate) の計算式

$$\text{遵守確率 (\%)} = \begin{cases}
100 & (\text{loyalty} \ge 51 \text{ または親愛状態}) \\
\text{loyalty} \times 1.8 & (1 \le \text{loyalty} \le 50) \\
0 & (\text{loyalty} = 0)
\end{cases}$$

### 4.2 指示無視時の代替行動
指示遵守判定（1〜100の乱数抽選）に失敗した場合、モンスターは作戦指示を無視し、以下のいずれかの代替行動をとります。

- **`loyalty` 0**: 50% の確率でプレイヤーへ攻撃を仕掛ける（反逆）、またはランダムな方向へ暴走移動する。
- **`loyalty` 1〜50**: 作戦指示を無視し、種族デフォルトの `NORMAL` AI や「その場であくびをする（あくび待機）」行動に置き換わります。

## 5. ドメインモデルとデータ構造拡張

### 5.1 `MonsterInstanceDomain` の拡張フィールド
`MonsterInstanceDomain`（[Monster ドメインモデル](./domain_models/Monster.md)）に以下の属性を追加します。

```json
{
  "instanceId": "mon_inst_77821",
  "monsterId": "slime_001",
  "userId": "usr_9921",
  "currentTactic": "SAFETY_FIRST",
  "loyalty": 180,
  "isAffection": false
}
```

- **`currentTactic`**: 現在設定されている作戦コード（Enum: `FULL_POWER`, `SAVE_RESOURCES`, `SAFETY_FIRST`, `FOLLOW_ME`, `FREE_ACTION`, `STAY_WAIT`）。デフォルトは `FREE_ACTION`。

## 6. API 仕様

### 6.1 作戦指示照会 API
指定された仲間モンスターの現在の作戦設定と忠誠度状態を取得します。

- **HTTP Method**: `GET`
- **Endpoint**: `/api/v1/monsters/{instanceId}/tactics`

#### レスポンス JSON Schema (`200 OK`)
```json
{
  "instanceId": "mon_inst_77821",
  "userId": "usr_9921",
  "currentTactic": "SAFETY_FIRST",
  "loyalty": 180,
  "obedienceRate": 100.0,
  "isObeying": true
}
```

### 6.2 作戦指示変更 API
指定された仲間モンスターの作戦指示を更新します（単体またはパーティ一括）。

- **HTTP Method**: `PUT`
- **Endpoint**: `/api/v1/monsters/{instanceId}/tactics`

#### リクエスト JSON Schema
```json
{
  "userId": "usr_9921",
  "tactic": "FULL_POWER"
}
```

#### レスポンス JSON Schema (`200 OK`)
```json
{
  "instanceId": "mon_inst_77821",
  "userId": "usr_9921",
  "previousTactic": "SAFETY_FIRST",
  "updatedTactic": "FULL_POWER",
  "updatedAt": "2026-03-31T12:00:00Z"
}
```

## 7. ビジネスルール・エラーハンドリング

| エラーコード | HTTP ステータス | 発生条件 |
| :--- | :--- | :--- |
| `MONSTER_NOT_FOUND` | `404 Not Found` | 指定された `instanceId` のモンスターが存在しない。 |
| `MONSTER_NOT_OWNED` | `403 Forbidden` | 操作対象のモンスターが申請ユーザーの所有物でない。 |
| `INVALID_TACTIC_CODE` | `400 Bad Request` | 定義されていない無効な作戦コードが指定された。 |
| `MONSTER_DEFEATED` | `422 Unprocessable Entity` | 倒れて戦闘不能状態のモンスターで作戦を変更しようとした。 |

## 8. 今後の拡張
- **カスタム条件作戦（ガンビットシステム）**: 「HPが30%以下なら薬草を使う」「敵が3体以上なら範囲魔法を使う」といった、プレイヤーが独自のトリガー条件とアクションをプログラミングできる作戦構築機能。
- **作戦変更専用アイテム・コンボ**: 作戦変更時に一時的なステータスバフ（例: ガンガンいこうぜ変更ターンに攻撃力+15%）を付与する戦術アイテムの導入。
