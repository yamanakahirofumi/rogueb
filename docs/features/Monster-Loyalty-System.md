# モンスター忠誠度システム (Monster Loyalty System)

## 1. 概要
本ドキュメントは、プレイヤーと「仲間のモンスター」との間の絆を示す「忠誠度（懐き具合）」システムの仕様を定義します。忠誠度は、モンスターの戦闘中の挙動、ステータス、および進化に影響を与える重要なパラメータです。

## 2. 忠誠度の基本仕様
忠誠度は各モンスター個体（`MonsterInstanceDomain`）ごとに保持される数値データです。

- **値の範囲**: 0 〜 255
- **初期値**:
    - **捕獲直後**: 50（野生の状態から少し心を開いた状態）。
    - **孵化直後**: 120（生まれた時からプレイヤーを親と認識している状態）。

## 3. 忠誠度の増減メカニズム
プレイヤーとの行動やアイテムの使用によって数値が変動します。

### 3.1 増加条件
| アクション | 変動値 | 備考 |
| :--- | :---: | :--- |
| **同行して歩く** | +1 | パーティ（Active Party）に編入された状態で 100 歩 (`subStep`) 経過。 |
| **レベルアップ** | +5 | 戦闘またはアイテムによるレベル上昇時。 |
| **戦闘に勝利** | +1 | 敵モンスターを撃破した際に、戦闘に参加していた場合。 |
| **好物アイテムの使用** | +10 〜 +30 | 「懐きクッキー」など、特定のアイテムを使用。 |

### 3.2 減少条件
| アクション | 変動値 | 備考 |
| :--- | :---: | :--- |
| **戦闘不能（HP 0）** | -20 | 戦闘で倒され、変身解除または拠点へ戻された場合。 |
| **長期間の放置** | -1 / 日 | 拠点や倉庫に預けたまま、現実時間で 24 時間経過。 |
| **嫌いなアイテムの使用** | -10 | 苦い薬など、モンスターが嫌がるアイテムを無理に使用。 |

#### 長期間の放置による減少の計算（Lazy Calculation）
放置による減少は、モンスターが「アクティブ」になった際（パーティ編入や詳細画面の表示時）に、前回更新時（`lastLoyaltyUpdate`）からの経過日数を計算して一括適用されます。

**計算式**:
`減少値 = min(現在の忠誠度, (現在時刻 - lastLoyaltyUpdate) / 86400秒)`

## 4. 忠誠度の影響

### 4.1 戦闘中の挙動
忠誠度が極端に低い場合、モンスターがプレイヤーの指示を無視することがあります。また、忠誠度が高いと致命的なダメージを耐えることがあります。

- **指示無視**:
    - **忠誠度 0 〜 30**: 25% の確率で行動を拒否し、そのターンは「何もしない（Wait）」になります。
    - **忠誠度 31 〜 50**: 10% の確率で行動を拒否します。
    - **忠誠度 51 以上**: 常に指示に従います。
- **食いしばり (Brace)**:
    - **忠誠度 151 〜 200**: HP が 2 以上の状態で致命的なダメージを受けた際、**10%** の確率で HP 1 で耐えます。
    - **忠誠度 201 〜 255**: 同条件において、**25%** の確率で HP 1 で耐えます。

### 4.2 ステータス補正（絆ボーナス）
忠誠度が高い個体は、プレイヤーへの信頼によって能力が向上します。

- **忠誠度 200 〜 250**: すべての基本ステータス（HP, MP 除く）に **+3%** のボーナス。
- **忠誠度 251 〜 255**: すべての基本ステータスに **+5%** のボーナス、およびクリティカル率に **+5%** の固定ボーナス。

### 4.3 進化への影響
一部のモンスター種族において、進化の条件として「一定以上の忠誠度」が必要となります。
詳細は [モンスター進化システム](./Monster-Evolution-System.md) を参照してください。

## 5. 忠誠度の確認方法
- **ステータス画面**: モンスターの詳細画面で、数値に応じたテキストが表示されます。

| 忠誠度範囲 | テキスト表示（例） | 状態の要約 |
| :--- | :--- | :--- |
| 0 〜 20 | 「強い敵意を感じる……」 | 隙あらば攻撃してきそうなほど険悪な状態。 |
| 21 〜 50 | 「こちらを警戒している。」 | まだ信頼関係が築けていない状態。 |
| 51 〜 100 | 「指示を待っている。」 | 最低限の主従関係ができている状態。 |
| 101 〜 150 | 「こちらを信頼しているようだ。」 | 仲間としての絆が芽生え始めた状態。 |
| 151 〜 200 | 「とても懐いている！」 | 強い絆で結ばれている状態。 |
| 201 〜 255 | 「固い絆で結ばれている！！」 | 互いに魂で通じ合っている最高の状態。 |

- **拠点の NPC**: 「懐き具合」を診断してくれる NPC が、正確な数値を教えてくれる場合があります。

## 6. データ構造
`MonsterInstanceDomain` に以下のフィールドを追加します。

- `loyalty`: Integer（0 〜 255）
- `lastLoyaltyUpdate`: Long（最終忠誠度更新タイムスタンプ）

## 7. API 仕様

### 7.1 アイテム給餌（忠誠度変動）エンドポイント
所持中のアイテム（クッキー等）をモンスターに与えて忠誠度を上昇/減少させます。

- **HTTP メソッド**: `POST`
- **パス**: `/api/v1/monsters/loyalty/feed`

#### リクエスト JSON スキーマ例
```json
{
  "playerId": "player_999",
  "monsterInstanceId": "mon_inst_12345",
  "itemInstanceId": "item_cookie_001"
}
```

#### レスポンス JSON スキーマ例 (成功時 - HTTP 200)
```json
{
  "success": true,
  "monsterInstanceId": "mon_inst_12345",
  "previousLoyalty": 120,
  "currentLoyalty": 140,
  "loyaltyDelta": 20,
  "statusText": "「こちらを信頼しているようだ。」",
  "message": "モンスターに懐きクッキーを与えました。"
}
```

### 7.2 忠誠度照会エンドポイント
特定モンスターの現在の忠誠度およびテキスト表示状態を取得します。

- **HTTP メソッド**: `GET`
- **パス**: `/api/v1/monsters/{instanceId}/loyalty`

#### レスポンス JSON スキーマ例 (成功時 - HTTP 200)
```json
{
  "monsterInstanceId": "mon_inst_12345",
  "loyalty": 140,
  "lastLoyaltyUpdate": 1700000000,
  "statusText": "「こちらを信頼しているようだ。」",
  "braceProbability": 0.0,
  "statBonusPercent": 0
}
```

## 8. エラーハンドリング仕様

| エラーコード | HTTPステータス | 発生条件 | エラーメッセージ例 |
| :--- | :---: | :--- | :--- |
| `MONSTER_NOT_FOUND` | 404 | 指定された `monsterInstanceId` が存在しない、または所有権がない。 | 指定されたモンスターが見つかりません。 |
| `ITEM_NOT_FOUND` | 404 | 指定された `itemInstanceId` が存在しない。 | 指定されたアイテムが見つかりません。 |
| `ITEM_NOT_IN_INVENTORY` | 400 | アイテムがプレイヤーの所持品内に存在しない。 | 指定されたアイテムを所持していません。 |
| `INVALID_ITEM_TYPE` | 400 | 指定されたアイテムが忠誠度に影響を与えるアイテム（給餌用）ではない。 | このアイテムはモンスターに与えることができません。 |
| `MAX_LOYALTY_REACHED` | 400 | 忠誠度が既に上限（255）に達しており、これ以上上昇するアイテムを使用できない。 | 忠誠度が既に最大値に達しています。 |

## 9. 今後の拡張
- **モンスター親愛システム**: 忠誠度が最大値(255)かつレベル20以上に達したときに解放されるシステム。詳細は **[モンスター親愛システム](./Monster-Affection-System.md)** を参照してください。
- **特殊演出**: 忠誠度が高いと、戦闘中にプレイヤーをかばう、あるいは状態異常を自力で治す等の特殊演出が発生する。
