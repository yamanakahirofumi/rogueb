# UI-UX 設計 (UI-UX Design)

## 1. 概要
本ドキュメントは、RogueBにおけるユーザーインターフェース（UI）およびユーザーエクスペリエンス（UX）の設計方針を定義します。本ゲームはマルチプレイヤー・ローグライクであり、探索と建築、そして経済活動をシームレスに行えるUIを目指します。

## 2. 画面構成
主要なゲーム画面は、以下の 4 つのエリアで構成されます。

### 2.1 メインビュー（ダンジョン表示エリア）
- **役割**: ダンジョンのタイル、プレイヤー、モンスター、アイテムを表示します。
- **表示形式**: グリッドベースのタイル表示。
- **視界制限**: プレイヤーの周辺（視界範囲内）のみが明るく表示され、それ以外は暗転（未探索）または半透明（既探索だが現在は見えない）となります。

### 2.2 ステータスバー（上部）
- **表示項目**:
  - プレイヤー名 / レベル
  - HP（現在値 / 最大値）のバー表示
  - スタミナ（空腹度等）
  - 所持ゴールド
  - 現在の階層（例: B5F）

### 2.3 メッセージログ（下部）
- **役割**: ゲーム内で発生したイベント（攻撃、アイテム拾得、階段昇降など）をテキストで通知します。
- **UX**: 重要なイベント（ダメージを受けた、レベルアップ等）は色を変えて強調します。

### 2.4 サイドパネル / メニュー
- **役割**: 状況に応じて以下の情報を表示します。
  - **ミニマップ**: フロア全体の探索状況。
  - **インベントリ（Bag）**: 所持アイテムの一覧と操作（使う、捨てる、装備）。
  - **モンスター情報**: 捕獲・所持しているモンスターの状態。

## 3. 操作フィードバック
- **移動**: キー入力に対し、即座に座標が更新されます（リアクティブなレスポンス）。
- **戦闘**: 攻撃ヒット時に画面の揺れ（スクリーンシェイク）や、ダメージ数値のポップアップを表示します。
- **アイテム**: 拾得時にメッセージログへの表示に加え、効果音（SE）によるフィードバックを行います。

## 4. 特殊画面の UI 設計

### 4.1 ダンジョンエディタ（管理者モード）
- ツールボックス形式でタイルやモンスターを選択し、マップ上に配置する UI。
- グリッドガイドの表示。

### 4.2 ショップ UI
- 店主の在庫リストとプレイヤーの所持アイテムを並列表示。
- 基本価格と現在価格（管理者が設定）を比較できるインターフェース。

## 5. デザイン規約
- **フォント**: 視認性の高い等幅フォント（Monospaced Font）を推奨。
- **カラーパレット**:
  - 壁: 暗いグレー
  - 床: 明るいグレー / ベージュ
  - プレイヤー: 黄色 / 白色
  - モンスター: 赤色 / 紫色
  - ゴールド: 金色

## 6. UI演出・フィードバック制御仕様

UIのレスポンス性やゲームの「手触り（プレイ感覚）」を向上させるため、クライアント演出パラメータおよびサーバーからの演出連動イベント（SSE/WebSocket）のJSON構造を定義します。

### 6.1 フィードバック演出パラメータ
各ゲームイベント発生時にクライアント側で実行される視覚・音響演出の標準パラメータです。

| アクション種別 | ヒットストップ (ms) | スクリーンシェイク (強度/時間) | ダメージポップアップ演出 | SEイベントID |
| :--- | :--- | :--- | :--- | :--- |
| **通常物理攻撃** | 50ms | 弱 (3px / 100ms) | 赤色数値、上方スライド | `se_attack_hit` |
| **クリティカル攻撃** | 150ms | 強 (8px / 250ms) | 黄色・大フォント、フラッシュ | `se_critical_hit` |
| **痛恨の被ダメージ** | 100ms | 中 (5px / 200ms) | 赤色・大フォント、画面赤フラッシュ | `se_player_damaged` |
| **回復（ポーション）** | 0ms | なし | 緑色数値、上方スライド | `se_heal` |
| **アイテム拾得** | 0ms | なし | ポップアップアイコン＋ログ表示 | `se_item_pick` |
| **レベルアップ** | 200ms | 画面全体光演出 (500ms) | 「LEVEL UP!」エフェクト | `se_level_up` |
| **罠作動** | 100ms | 中 (5px / 150ms) | 紫色数値/効果テキスト | `se_trap_trigger` |

### 6.2 演出連動イベントJSON構造 (SSE Payload)
リアルタイム同期時にクライアントがUI描画・演出実行を行うためのイベントデータ構造です。

```json
{
  "type": "UI_FEEDBACK_EVENT",
  "timestamp": 1698393600000,
  "payload": {
    "actionType": "CRITICAL_ATTACK",
    "sourceEntityId": "player-123",
    "targetEntityId": "monster-456",
    "targetCoordinate": {
      "x": 10,
      "y": 12
    },
    "value": 42,
    "hitStopDurationMs": 150,
    "screenShake": {
      "intensity": "HIGH",
      "durationMs": 250
    },
    "popupText": "CRITICAL 42!",
    "soundEffectId": "se_critical_hit"
  }
}
```

## 7. エラーハンドリングとUI表示マッピング

バックエンドから返却されるエラーコードに対応したUI側の表示方式（トースト通知、ダイアログ、メッセージログ）およびSEトリガーのマッピング仕様です。

### 7.1 UIエラーマッピングテーブル

| エラーコード | UI表示タイプ | ログ/通知メッセージテンプレート | SEトリガー |
| :--- | :--- | :--- | :--- |
| `BAG_FULL` | トースト通知 | バックが満杯のため、これ以上アイテムを持てません。 | `se_error_buzz` |
| `STAMINA_EXHAUSTED` | メッセージログ (警告色) | 空腹で倒れそうだ！スタミナが切れています。 | `se_warning_stamina` |
| `STATUS_PREVENTS_MOVEMENT` | トースト通知 | 身体が動かない！（状態異常により行動不能） | `se_error_buzz` |
| `TILE_BLOCKED` | 簡易警告 | そこへは進めません。 | `se_bump_wall` |
| `INSUFFICIENT_GOLD` | ダイアログ | ゴールドが不足しています。 | `se_error_buzz` |
| `INSUFFICIENT_MP` | トースト通知 | MPが足りません。 | `se_error_buzz` |
| `STORAGE_FULL` | ダイアログ | 倉庫の空き容量が足りません。 | `se_error_buzz` |
| `UNCAPTURABLE_STATUS` | トースト通知 | この状態のモンスターは捕獲できません。 | `se_error_buzz` |

### 7.2 エラーダイアログレスポンス例

```json
{
  "errorCode": "INSUFFICIENT_GOLD",
  "message": "ゴールドが不足しています。",
  "uiConfig": {
    "displayType": "DIALOG",
    "title": "購入失敗",
    "seId": "se_error_buzz",
    "autoCloseMs": 0
  }
}
```

## 8. プレイ感覚・手触り微調整パラメータ詳細 (Playfeel Fine-Tuning Parameters)

ゲームの快適性や「動かしていて気持ちいい」手触りを実現するため、入力レスポンス、移動アニメーション補間、効果音（SE）挿入タイミングオフセット、ヒットストップ減速曲線、および各種表示タイムラインの制御仕様を定義します。

### 8.1 入力レスポンスおよび先行入力バッファ仕様

ターン制ローグライクにおける操作の追従性を高めるための入力受付制御ルールです。

| 項目 | パラメータ値 | 動作仕様 |
| :--- | :--- | :--- |
| **先行入力バッファ** | `150ms` | ターン処理アニメーション中に受信した次の移動/攻撃入力を最大 150ms 保持し、ターン終了直後に即座に実行する。 |
| **長押し移動初期ディレイ** | `200ms` | 方向キー長押し開始から連続移動モードに移行するまでの待機時間。誤操作による移動オーバーシュートを防止する。 |
| **連続移動ステップ間隔** | `60ms / tile` | 連続移動モード中の 1 マスあたりの移動ピッチ（1 秒間に約 16.6 マス移動）。 |
| **キー離し慣性キャンセル** | `即時 (0ms)` | キー離下イベント検知時、進行中のタイル移動完了時点で連続移動を即座に停止する。 |

### 8.2 移動およびアニメーション補間仕様

グリッド間移動や視覚効果の滑らかさを担保するフレーム・補間計算パラメーターです。

| 演出項目 | 補間時間 (ms) | イージング関数 | 補足・効果詳細 |
| :--- | :--- | :--- | :--- |
| **1タイル通常移動** | `60ms` | `ease-out` | 始点から終点への滑らかな移動。 |
| **斜め移動** | `70ms` | `ease-out` | X/Y 軸同時補間。壁の角での視覚的引っ掛かりを防止。 |
| **階段昇降・ワープ** | `400ms` | `ease-in-out` | フェードアウト (150ms) → 画面更新 (100ms) → フェードイン (150ms)。 |
| **攻撃振り下ろしモーション** | `80ms` | `ease-in` | 攻撃対象の方向へ 4px 押し出し後、元の位置へ復帰。 |

### 8.3 ヒットストップ減速曲線とスクリーンシェイクモデル

ダメージ打撃時の手触りを強調するためのヒットストップ減速（Time Scale）およびシェイク振動パラメータです。

#### ヒットストップ減速曲線 (Hit-Stop Time Scale)
打撃の瞬間にゲーム時間の進みを一時的に遅延させ、手応えを演出します。
- **通常攻撃**: 時間スケール `0.1x` (50ms 保持) → `1.0x` へ直線復帰 (20ms)。
- **クリティカル攻撃**: 時間スケール `0.0x` 完全停止 (150ms 保持) → `1.0x` へイージング復帰 (50ms)。

#### スクリーンシェイク振動モデル (Damped Harmonic Oscillator)
減衰振動モデルに基づき、自然で心地よい画面揺れを計算します。
- **弱シェイク (`se_attack_hit`)**: 振幅 $A = 3\text{px}$, 減衰係数 $\gamma = 25$, 周波数 $\omega = 60\text{Hz}$, 継続時間 $100\text{ms}$
- **強シェイク (`se_critical_hit`)**: 振幅 $A = 8\text{px}$, 減衰係数 $\gamma = 15$, 周波数 $\omega = 50\text{Hz}$, 継続時間 $250\text{ms}$

### 8.4 効果音 (SE) 挿入タイミングオフセット

アニメーション画像と音響の同期のズレを解消し、打撃感や取得感を最大化するためのミリ秒単位のオフセット設定です。

| アクション / イベント | SE イベント ID | SE 発火オフセット (ms) | 発火タイミングの基準点 |
| :--- | :--- | :--- | :--- |
| **足音（移動）** | `se_step` | `0ms` | タイル移動アニメーション開始時 |
| **攻撃振り下ろし** | `se_swing` | `+10ms` | 攻撃モーション開始 10ms 後（振りかぶり感） |
| **攻撃ヒット（打撃）** | `se_attack_hit` | `+60ms` | 攻撃モーションが対象に到達した瞬間 |
| **アイテム拾得** | `se_item_pick` | `0ms` | アイテム上に乗った瞬間 |
| **ポーション消費** | `se_drink` | `+50ms` | 回復エフェクト表示開始 50ms 後 |
| **レベルアップ** | `se_level_up` | `+100ms` | 全面光演出の光量ピーク時 |

### 8.5 ダメージポップアップおよびパーティクルタイムライン

テキストやエフェクトの表示フェーズを定義します。

```
[0ms] 生成・出現 (スケール 1.3x 拡大、Alpha 1.0)
  ↓ (30ms: インパクトフェーズ)
[30ms] 通常サイズ復帰 (スケール 1.0x)
  ↓ (200ms: 上方スライドフェーズ - 16px 浮上)
[230ms] フェードアウト開始 (Alpha 1.0 → 0.0)
  ↓ (100ms: 消滅フェーズ)
[330ms] オブジェクト破棄 (画面から消去)
```
